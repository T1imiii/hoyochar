# Blueprint

## Overview

This project is a web application for fans of HoYoverse games. It provides a centralized catalog of characters from games like Genshin Impact, Honkai Star Rail, and Zenless Zone Zero. The application also includes a music player with soundtracks from the games.

## Project Structure and Design

*   **`index.html`**: The main entry point of the application.
*   **`style.css`**: Main stylesheet for the application.
*   **`main.js`**: Main JavaScript file for application logic.
*   **`music.css`**: Stylesheet for the music player.
*   **`music.js`**: JavaScript for the music player functionality.
*   **`*.json`**: Data files for characters and music.
*   **`images/`**: Contains all the images for the application.
*   **`music/`**: Contains all the music files for the application.

## Current Task: Full HD Adaptation

The goal of this task is to make the website responsive for Full HD (1920px) screens.

### Plan

1.  Analyze the current CSS to identify styles that need to be adjusted.
2.  Add media queries to `style.css` to adjust the layout and font sizes for screens with a maximum width of 1920px.
3.  Add media queries to `music.css` to ensure the music player is also responsive.
4.  Adjust the position of the music player on the music page for 1920px screens to be slightly higher.
5.  Adjust the layout of the home page to fit on a single screen without scrolling at 1920px resolution.
6.  Verify that the changes do not break the existing layout for larger screens.
